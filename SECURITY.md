# Security

CoverFlow is an early-preview web extension. Keep Jellyfin and its injection
dependencies updated and back up the server before installing third-party code.

Please do not disclose an exploitable security issue, credentials or private
library data in a public issue. Use this repository's **Security → Report a
vulnerability** option for a private report. If that option is unavailable, open
an issue asking for a private reporting channel without disclosing the details.

Include the affected plugin and Jellyfin versions, a minimal reproduction and
the expected security boundary. Redact secrets and do not attach real tokens.

Only the latest preview is actively maintained. Fix timing is best effort;
this volunteer project does not provide a security response SLA.
